# 🎯 Reflex Arena

Reflex Arena 是一款輕量級、純前端的反應力點擊遊戲。  
玩家需在 60 秒內快速點擊隨機出現的目標，維持連擊（Combo）來獲得更高分數。隨著連擊數提升，遊戲節奏將逐漸加快，挑戰你的專注力與即時反應能力。

---

## ✨ Features

- ⏱ 60 秒限時挑戰
- 🔥 Combo 連擊系統（連續命中可倍增得分）
- ⚡ 目標生成速度隨連擊逐步加快
- 🔊 使用 Web Audio API 產生即時音效回饋
- 🎨 純 CSS 動畫與視覺效果

- 🚀 單一 HTML 檔即可執行，零相依

- **HTML5**

---

## ▶️ How to Play

1. 點擊畫面中出現的紅色圓形目標
2. 每次成功命中可獲得分數並提升 Combo
3. 若目標消失未點擊，或點擊空白區域，Combo 將重置
4. 60 秒結束後顯示最終分數
5. 點擊 **Restart** 可重新開始遊戲
